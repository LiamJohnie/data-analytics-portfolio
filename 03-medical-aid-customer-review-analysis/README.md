# PDAN8411 POE Part 3: Medical Aid Customer Review Analysis

Topic modelling and sentiment analysis of insurance customer reviews, used as a proxy to surface broad areas of concern and overall customer sentiment for a South African medical aid.

## Files
- `Medical_Aid_Review_Analysis.ipynb`: full analysis (EDA, LDA topic modelling, supervised sentiment, cross-analysis).
- `PDAN8411_POE_Part3_Report_ST10536072.pdf`: final report.
- `figures/`: charts generated by the notebook and embedded in the report.
- `requirements.txt`: Python dependencies.
- `data/`: place the dataset CSV here (not committed; see Dataset).

## Dataset
Rihab, 2021. Reviews about insurance companies. Kaggle. https://www.kaggle.com/datasets/ghrabmed/reviews-about-insurance-companies

Download the CSV and place it in `data/`. The notebook loads the first CSV found in that folder.

## Running it
1. Install dependencies: `pip install -r requirements.txt`
2. The Libraries cell downloads the required NLTK resources on first run.
3. Run the notebook top to bottom (Kernel > Restart & Run All).

Python 3.10+. The cached `.joblib` files regenerate automatically if absent.
